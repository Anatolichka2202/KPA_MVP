# KPA_MVP

Исторический прототип Qt-интерфейса ЯВ/БКД, один из ранних этапов стендового направления. Не является завершённым самостоятельным продуктом.

- `core/` — протокольные модели и заготовки сетевой/прикладной логики.
- `gui/` — интерфейс и представления.
- `yv_config.ini` — проектная конфигурация.

Корневой CMake подключает `core` и `gui`; объявление списков исходников само по себе не создаёт исполняемую цель. Воспроизводимая сборка приложения здесь не подтверждена.

Смежная историческая база: [KPA_COMPLEX](https://github.com/Anatolichka2202/KPA_COMPLEX). Действующая линия универсального приложения: [MilTechStation](https://github.com/Anatolichka2202/KPA-YALK_MODULE). Совместимость старых моделей с ней автоматически не подразумевается.
